Cull rule (reference = entity_cull_reference on CPU, mirrored by the shader):
  alpha-interpolate: pos = mix(prev,curr,alpha); yaw = prev + wrap_pi(curr-prev)*alpha  (wrap_pi to [-pi,pi]).

Animation sampling (shader and CPU reference identical):
  f = anim_t*ANIM_FPS; loop: f = mod(f,count) else f = min(f, count-1); f0=floor(f); fr=f-f0;
  f1 = loop ? (f0+1)%count : min(f0+1,count-1); rows = vat.row_base + start + f0 / f1; part matrix = lerp(m(f0), m(f1), fr) (3x4 rows).
